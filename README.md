# fachrulfnd — Web3 Strategist & AI Agent Builder

Personal portfolio and project showcase. Built with Next.js 15 and Tailwind CSS.

## Tech Stack

- Next.js 15 (App Router)
- React 19
- Tailwind CSS 4
- TypeScript 5

## Sections

- **Hero** — Introduction and value proposition
- **Selected Work** — 3 showcase projects
- **Skills & Expertise** — Web3, AI/Agents, Engineering
- **Contact** — GitHub, X, LinkedIn, Email

## Setup

```bash
npm install
npm run dev
```

Open http://localhost:3040

## Build

```bash
npm run build
npm start
```

## Deploy

1. Push to GitHub
2. Import repository into [Vercel](https://vercel.com)
3. Done — auto-deploys on push

Or deploy from CLI:

```bash
vercel
```

## Customize

Edit `src/data/config.ts` for profile info.
Edit `src/data/projects.ts` for project cards.
